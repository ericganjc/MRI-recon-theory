## 三、用户的深层工作模式（继承自 chap2）

1. **逐行审阅 · 手术刀精度**：用户不是在"读"文档，而是在逐行做数学验证。会注意到角标位置、求和号有无、取实部是否缺失、矩阵形式是否一致。
2. **追问链驱动**：每次脚注添加后，用户会顺着新信息追问更深的问题（"为什么列满秩？→ 为什么全采样？→ 适用条件是什么？"），形成追问链。
3. **先自己动手再求助**：当发现推导问题时，用户会先自己尝试修改，再让 AI 检查剩余部分。
4. **初学者定位 ≠ 低要求**：用户反复自称为"初学者"，但实际审阅深度相当于同行评议。这个定位的含义是"请从基础讲起，不要跳过推理步骤"，而非"可以降低严谨度"。
5. **先分析后动文档**：用户问"是不是错了？如果是就勘误，如果不是告诉我为什么（先不用修改文档）"——此类提问默认不改文件，先给结论+论证，用户确认后再动。
6. **留占位符的协作**：用户改写后会留空占位（如 `\footnote{勘误：}`）或指定标签/开头，AI 填入时保留用户标签与开头、只补内容；多勘误点用①②分条。
7. **省 token 工作方式（S2 定案）**：不每轮更新 HANDOFF/LEARNINGS——长对话结束时由用户手动要求总结，再统一写入；不每次修改后编译（必要时才编译）；回复抓主要矛盾、不堆砌。
8. **严格推导按需触发**：推导条件的检查（可逆性/正定性/秩等）仅在用户明确要求严格数学推导时执行，不必每次自动展开。

## 四、高频踩坑模式（跨会话重复出现）

| 踩坑模式 | 具体表现 |
|:---|:---|
| **正则化项丢失** | 推导中定义时包含正则化，中间步骤丢失，结尾又补回 |
| **矩阵形式混用** | 同一矩阵时而块对角、时而纵堆叠，全文不一致 |
| **取实部操作遗漏** | 原文省略取实部 $\Re$，导致推导跳步 |
| **适用条件缺失** | 给出显式解但未注明矩阵可逆/列满秩条件 |
| **复共轭 vs 转置混淆** | 非实矩阵情况下 Hermitian 共轭 $\mathbf{A}^H$ 与普通转置 $\mathbf{A}^T$ 的区别被忽略 |
| **并行编辑碰撞** | AI 执行 Edit 时用户正并行改写同一段落，old_string 不匹配；处理：Read 后基于用户新行文改编，不恢复 AI 版本 |

## 五、标准操作流程

**当用户要求"在 X 行添加某概念的脚注"时**：
1. **定位**：精确读取目标行上下文
2. **定义**：给出概念的严格数学定义（函数签名 + 矩阵形状 + 元素公式）
3. **含义**：物理/几何直觉解释
4. **关联**：说明该概念在当前推导中扮演的角色
5. **勘误**（如适用）：指出原文对此概念的使用是否有不严谨之处

**当用户要求"梳理全文"时**，三类处理泾渭分明：
1. 明确错误（错别字、失效引用、漏因子、下标错误、字体约定违反）→ 直接修复，修复后**逐条汇报**，数学内容修正单独加粗提示请用户复核
2. 存疑内容（原文记号含糊、疑似笔误）→ 只列清单供用户决策，不擅自改动、不反问

**当用户要求写/重写章节摘要时**（S3 定案完整版）：两段式——第一段以"本报告基于《Magnetic Resonance Image Reconstruction: Theory, Methods, and Applications》第X章内容，从……出发，通过数学推导梳理了……"开头，概述全文脉络（书名固定为此，**此后各章一律沿用**）；第二段先写对原文的勘误补全工作，再写个人感悟（**感悟句由用户指定，照录**）。用户偏好简洁，AI 初稿偏长时用户会自行精简。

**当用户要求核查附录时**：名录一律按**正文首次出现顺序**排列（可用脚本扫描行号排序，避免目测错位）；逐条核对锚点 `\label{term:XX}` 与索引 `\pageref` 一一对应（不存在的条目会渲染成 ??，须删）；正文格式变更（如新增术语全称、符号改名）必须同步附录；表格超页时按内容自然边界拆为多个 table 浮动体，格式与表头行保持一致。

**跨章节工作流程（S3 定案，此后每章沿用）**：
1. **收尾阶段**：把本章 HANDOFF/LEARNINGS 更新到最新版本（会话记录、文件状态、待决策项），并在下一章目录新建继承版 HANDOFF/LEARNINGS——只搬跨章内容（工作模式、行文风格、术语与符号约定、编译习惯、踩坑模式），本章特有的细节问题与具体公式不继承。

**新增约定（S3 定案，自第四章起生效）**：① 正文不出现参考文献引用，`\cite` 一律不用；② 图片由 AI 预留 `\includegraphics` 占位与图注，用户自行补图。

**编译与记录时机（S2 定案）**：修改后不默认编译；HANDOFF/LEARNINGS 不每轮更新——长对话结束时由用户手动要求（总结、编译验证）再执行。

## 六、符号与措辞约定

- 矩阵加粗正体 `\mathbf`，向量加粗斜体 `\bm`
- **用户自身符号习惯优先于声明约定**：某符号全文使用风格一致时（即使与声明不符）不得批量替换，只提示差异、由用户决定
- 虚数单位用 $i$ 不用 $j$（如 $e^{i2\pi}$）；`\max` 类算子用 operator 形式（$k_{\max}$ 而非 $k_{max}$）
- 严谨措辞："满秩"统一为"列满秩"（显式解适用条件）
- 中文术语示例：人为选定（非"认为选定"）、实物理量（非"实物量"）、高维度（非"高纬度"）、运动校正（非"运动矫正"）
- 聊天中公式用 Unicode 数学符号（𝒟、∇、θ、Σ、⁻¹、‖·‖₂、≈、→ 等），不要推荐 claude.ai 同步方案（用户使用外部 DeepSeek API，官方不可用）——详见 [LEARNINGS.md](LEARNINGS.md)
- 术语格式：首次出现 中文（English Full Name，ABBR），后文只用缩写；附录 B 索引按正文首次出现顺序，页码用 `\label{term:XX}` + `\pageref` 自动跟踪——详见 [LEARNINGS.md](LEARNINGS.md)
- 梯度约定（会话 S1 定案，勿跨章"统一"）：第二章(28) 无 ½、梯度含因子 2；第三章(3.4) 有 ½、梯度无因子 2，与式(3.6)/(3.8) 自洽——详见 [LEARNINGS.md](LEARNINGS.md)
- 范数约定（会话 S2 定案）：谱范数写 $\|\cdot\|_2$（矩阵算子范数），首次出现处有定义脚注；矩阵 1-范数（最大列和）与谱范数不混用
- 迭代次数约定（会话 S2 定案）：迭代次数一律用下角标（$\bm{x}_t$、$\bm{p}_{t+1}$）；上角标留给转置/共轭/幂次/方法标签，极小值点 $\bm{x}^*$、凸共轭 $g^*$ 不变——详见 [LEARNINGS.md](LEARNINGS.md)
- 插入式编号约定（S2 形成）：非原文新增公式用 `equ:3.X.0` 式标签（如 equ:3.5.0、equ:3.13.0），不挤占原文编号
